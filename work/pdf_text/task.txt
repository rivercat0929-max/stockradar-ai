Codex 开发任务：AI 股票雷达 MVP
你现在是全栈开发工程师，请根据下面的 PRD 开发一个可运行的 MVP Web 应用。
一、开发目标
开发一个名为「AI 股票雷达 / StockRadar AI」的股票分析 MVP。
第一版目标不是做真实交易，也不是提供投资建议，而是实现：
用户可以添加自选股；
用户可以录入持仓；
系统展示股票价格、评分、提醒和基础分析；
系统生成每日 AI 投资简报；
系统提供简单的历史信号回测展示；
页面结构清晰，后续方便扩展真实 API。
二、技术栈要求
请使用：
Frontend：Next.js + TypeScript + Tailwind CSS
Backend：Next.js API Routes 或 Server Actions
Database：PostgreSQL；如果暂时没有数据库，可先用 Prisma + SQLite 本地开发
ORM：Prisma
Chart：Recharts 或 Lightweight Charts
UI：简洁、现代、金融工具风格
部署目标：Vercel

十、开发要求
先创建完整项目结构；
所有页面必须能正常打开；
UI 要简洁，不要太花；
表格要清晰；
使用 TypeScript 类型定义；
评分、提醒、回测逻辑要模块化；
使用 mock data 时请集中放在 /lib/mock-data.ts；
业务逻辑放在 /lib/scoring.ts、/lib/backtest.ts、/lib/alerts.ts；
页面组件放在 /components；
请提供 README，说明如何安装、运行和后续接入真实 API。
十一、验收标准
完成后我需要能：
本地运行项目；
打开 Dashboard；
查看持仓；
添加或编辑一条持仓；
查看股票详情；
查看选股雷达；
查看事件日历；
查看回测结果；
看到每日 AI 简报；
看到免责声明。
请先实现 MVP，不要开发自动交易功能。
